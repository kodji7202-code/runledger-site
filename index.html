How it works

Agents now ship code. Nobody reads the transcript.

Runs happen unsupervised, logs run to thousands of lines, and risk hides in the details. RunLedger records each run, explains it, and lets you decide.

  1. 01

    Record

    Every step is captured while the agent works: files read and written, commands, API calls, model and tokens. It stays on your machine.

  2. 02

    Explain & score

    Each step gets a plain-language summary. The run gets a risk score with the reasons behind it.

  3. 03

    Decide

    Share the receipt with a teammate, guard risky commands before they run, or send sensitive actions for approval.

Real-time Guard

It stops risky commands before they run.

A Claude Code PreToolUse hook checks each action first. Dangerous commands are blocked, and sensitive ones wait for a human to approve them.

Features

Everything a reviewer needs, in one receipt.

Built for Claude Code first.

  • Run receipts

    Export each run as HTML, Markdown or JSON: files changed, commands and API calls, explained in plain language.

  • Cost & tokens

    Tokens and cost per step and per model. Haiku, Sonnet and Opus each handle the work they suit.

  • Risk score with reasons

    Flags secrets, deleted or skipped tests, rm -rf, force-push, sudo, curl | sh, hardcoded API keys and PowerShell.

  • Real-time Guard

    A Claude Code PreToolUse hook that blocks or asks before a risky action runs.

  • Human approvals

    Approve or deny from Slack, a webhook or the dashboard.

  • Team dashboard

    Cost by developer, model and project, plus risk trends over time.

  • GitHub PR comments

    A receipt comment on each pull request, with a CI fail threshold you set.

  • Per-project policies

    Set rules per repository in .runledger.json, so each project has its own limits.

FAQ

Questions, answered plainly.

Does my code leave my machine?

No. The CLI runs locally and writes receipts to your disk. The team server can be self-hosted. Receipts contain prompts and file paths, so you choose what to push.

Which agents does it support?

Claude Code today. Codex CLI and Aider are in beta, and any agent can use the open RunLedger JSON format.

How is cost computed?

From list prices for each model, applied to the token counts recorded for each step. It is an estimate, not an invoice. Check your provider's billing for exact amounts.

Will the guard slow my agent?

The guard is a local check that takes milliseconds. If it hits an internal error, it fails open, so an error never blocks your agent.
