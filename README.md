# runledger-site

The website for [RunLedger](https://runledger.site), a black box recorder for AI coding agents.
The product itself lives in [kodji7202-code/runledger](https://github.com/kodji7202-code/runledger).

## What is here

| File | Purpose |
| --- | --- |
| `index.html` | The landing page. HTML, CSS and JavaScript in one file, no build step. |
| `sample-receipt.html` | A real receipt, generated by the RunLedger CLI from the repository's sample session. Do not edit it by hand. |
| `privacy.html`, `terms.html` | Privacy policy and terms of use. |
| `404.html` | The page GitHub Pages shows for unknown addresses. |
| `page.css` | Shared styles for the secondary pages. |
| `fonts/` | Self-hosted Geist and Geist Mono (SIL Open Font License, see `fonts/OFL.txt`). |
| `favicon.svg`, `apple-touch-icon.png`, `og-image.png` | Icons and the social sharing image. |
| `robots.txt`, `sitemap.xml` | Search engine files. Update `lastmod` in the sitemap when a page changes. |
| `CNAME` | The custom domain for GitHub Pages. |

## Preview locally

The pages use root-relative paths (`/fonts/...`), so serve the folder instead of opening the file:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Regenerate the sample receipt

This page's example is actual CLI output from the fixture in the **RunLedger 0.4.1**
source tree, not a hand-edited mockup. Keep the sample's CLI version in sync with the
version stated in `index.html`.

With both repositories checked out in sibling folders:

```bash
cd ../runledger
HOME=/home/dev python -m runledger receipt tests/fixtures/sample_session.jsonl -o ../runledger-site/sample-receipt.html
```

`HOME=/home/dev` matches the fixture's home directory so it does not embed your
own local home path in the published receipt. On Windows PowerShell set
`$env:HOME = '/home/dev'` and `$env:USERPROFILE = '/home/dev'` before running
the equivalent `python -m runledger receipt` command.

Review generated samples for personal file paths, API keys or other sensitive
information **before committing**. Do not edit the generated receipt by hand.

## Third-party services

- **Formspree** receives the early-access form (`data-endpoint` on `#ea-form`). Without it, the form
  falls back to opening the visitor's mail app.
- **GoatCounter** counts visits without cookies (`kodji7209.goatcounter.com`). Links and buttons with
  `data-goatcounter-click` are counted as events.

Any new service that receives visitor data must be added to `privacy.html`.

## Deploy

GitHub Pages publishes the `main` branch. Every push to `main` goes live at https://runledger.site.
