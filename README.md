# runledger-site

The website for [RunLedger](https://runledger.site), a black box recorder for AI coding agents.
The product itself lives in [kodji7202-code/runledger](https://github.com/kodji7202-code/runledger).

## What is here

| File | Purpose |
| --- | --- |
| `index.html` | The landing page. Markup only, no build step. |
| `site.css`, `site.js` | Shared styles for every page, and the landing page's vanilla JavaScript (menu, copy button, reveals, receipt animation, guard demo). No libraries, no network requests. |
| `sample-receipt.html` | A real receipt, generated by the RunLedger CLI from the repository's sample session. Do not edit it by hand. |
| `privacy.html`, `terms.html` | Privacy policy and terms of use. |
| `404.html` | The page GitHub Pages shows for unknown addresses. |
| `fonts/` | Self-hosted Geist and Geist Mono (SIL Open Font License, see `fonts/OFL.txt`). |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `og-image.png` | Icons and the social sharing image. |
| `robots.txt`, `sitemap.xml` | Search engine files. Update `lastmod` in the sitemap when a page changes. |
| `CNAME` | The custom domain for GitHub Pages. |

`favicon.ico` must stay at the site root: `sample-receipt.html` declares no icon link, so browsers fall back to `/favicon.ico` for it, and a missing file fails the live-site check with a 404.

## Preview locally

The pages use root-relative paths (`/site.css`, `/site.js`), so serve the folder instead of opening the file:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Regenerate the sample receipt

This page's example is actual CLI output from the fixture in the **RunLedger 0.6.1**
source tree, not a hand-edited mockup. Keep the sample's CLI version in sync with the
version stated in `index.html`.

With both repositories checked out in sibling folders:

```bash
cd ../runledger
HOME=/home/dev python -m runledger receipt tests/fixtures/sample_session.jsonl --safe -o ../runledger-site/sample-receipt.html
```

`HOME=/home/dev` matches the fixture's home directory so it does not embed your
own local home path in the published receipt, and `--safe` shortens home folders to
`~` and masks e-mails. On Windows PowerShell set `$env:HOME = '/home/dev'` and
`$env:USERPROFILE = '/home/dev'` before running the equivalent
`python -m runledger receipt --safe` command.

Review generated samples for personal file paths, API keys or other sensitive
information **before committing**. Do not edit the generated receipt by hand.

## Third-party services

None. The site loads no analytics, forms, fonts or scripts from other origins. Any new service that
receives visitor data must be added to `privacy.html`.

## Deploy

GitHub Pages publishes the `main` branch. Every push to `main` goes live at https://runledger.site.
